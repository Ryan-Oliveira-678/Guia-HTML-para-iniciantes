Tags essenciais — uso muito frequente

HTML

O que é?

O elemento <html> representa o elemento raiz (root element) de um documento HTML. Ele tem como principal função envolver todo o conteúdo da página, sendo obrigatório que todos os outros elementos do código (como <head> e <body>) sejam descendentes diretos ou indiretos dele.

Sintaxe

                        <!doctype html>
                        <html lang="pt-BR">
                            <head>
                                <meta charset="utf-8">
                                <title>Título do Site</title>
                            </head>
                            <body>
                                <!-- Todo o conteúdo visual do site entra aqui -->
                            </body>
                        </html>

Principais atributos

  • lang: Especifica o idioma principal do documento (como "pt-BR" para português do Brasil ou "en" para inglês). Este atributo é considerado uma diretriz essencial de acessibilidade (WCAG), pois orienta os softwares de leitura de tela a usarem a pronúncia correta ao lerem o texto para usuários com deficiência visual, além de ser obrigatório para passar nos testes de validadores de código.
  • Atributos Globais: Aceita a aplicação de todos os atributos globais de marcação (como id, class e dir).

Exemplo visual

A tag <html> não produz uma renderização visual direta ou visível em si, mas atua como a moldura lógica invisível que define os limites e a estrutura da página inteira dentro do navegador.

Tag <head>

O que é?

O elemento <head> funciona como um contêiner para metadados (informações sobre a página) que não são visíveis diretamente para o usuário final. Ele abriga instruções técnicas fundamentais para que o navegador e os motores de busca compreendam a codificação de caracteres, o título da aba, os arquivos de estilização (CSS) e os scripts de comportamento (JavaScript) do site.

Sintaxe

                <!doctype html>
                <html lang="pt-BR">
                <head>
                    <meta charset="utf-8">
                    <title>Título do meu site</title>
                    <link rel="stylesheet" href="estilo.css">
                </head>
                <body>
                    <!-- Conteúdo visível do site -->
                </body>
                </html>

Principais atributos

A tag <head> aceita apenas os atributos globais comuns do HTML (como lang ou dir). Suas verdadeiras funções são estendidas por meio dos elementos fundamentais que ela abriga internamente:

  • <meta charset="utf-8">: Metadado essencial para garantir o suporte correto a emojis, acentos e múltiplos idiomas.
  • <title>: O elemento obrigatório que define o título exibido na aba do navegador e na indexação de buscas.
  • <link>: Associa recursos externos, como o arquivo CSS de estilos do site.
  • <style> e <script>: Elementos que permitem embutir códigos de estilização e scripts de interatividade diretamente na página.

Exemplo visual

A tag <head> em si não produz nenhum componente visual na tela de exibição do navegador. No entanto, ela afeta diretamente a apresentação visual (carregando os estilos CSS que colorem o site) e a identificação da página (atualizando o texto na aba de navegação).

Status: 🟢 HTML5 — Atual

Tag <body>

O que é?

O elemento <body> define o corpo do documento HTML e funciona como o contêiner principal para todo o conteúdo visível da página web. É dentro dele que inserimos textos, parágrafos, cabeçalhos, imagens, hiperlinks, tabelas, formulários, vídeos e faixas de áudio que o usuário final de fato vê e interage ao acessar o site. Só pode haver um único elemento <body> por documento.

Sintaxe

                    <!doctype html>
                    <html lang="pt-BR">
                    <head>
                        <meta charset="utf-8">
                        <title>Título da Aba</title>
                    </head>
                    <body>
                        <h1>Título Principal do Meu Site</h1>
                        <p>Este parágrafo e todos os outros elementos visuais ficam dentro do body.</p>
                    </body>
                    </html>

Principais atributos

A tag <body> aceita todos os atributos globais do HTML5, tais como:

  • id: Define um identificador único para o corpo da página, útil para estilizações ou manipulações de scripts específicos.
  • class: Associa uma ou mais classes de estilo para formatar o layout do site via CSS.
  • style: Permite declarar regras de estilo em linha diretamente no elemento, embora seja altamente desencorajado em ambientes de produção em prol de folhas de estilo externas.

Nota de Boas Práticas: Atributos de formatação visual antigos de versões anteriores do HTML (como bgcolor para cor de fundo, text para cor do texto ou background para imagem de fundo) estão totalmente obsoletos no HTML5. Toda a apresentação visual e o design do corpo do site devem ser controlados exclusivamente através de CSS.

Exemplo visual

A tag <body> representa a área inteira da janela de exibição do navegador. Tudo o que for digitado ou estruturado dentro dela será renderizado de forma visível na tela para o seu aluno.

Status: 🟢 HTML5 — Atual

Tag <title>

O que é?

O elemento <title> define o título do documento, que é exibido obrigatoriamente na barra de título do navegador ou na aba da página carregada. Ele é um elemento obrigatório em qualquer documento HTML e serve também como a descrição padrão quando um usuário salva a página nos favoritos. Além de sua importância visual de navegação, ele influencia diretamente o SEO (Search Engine Optimization), pois é o texto extraído pelos motores de busca para criar os links clicáveis nas páginas de resultados.

Sintaxe

                    <!doctype html>
                    <html lang="pt-BR">
                        <head>
                            <meta charset="utf-8">
                            <title>Aprenda HTML do Zero - Guia Prático</title>
                        </head>
                        <body>
                        <!-- O conteúdo da página entra aqui -->
                        </body>
                    </html>

Principais atributos

A tag <title> aceita apenas os atributos globais do HTML. Ela não possui atributos específicos e deve conter apenas texto puro; qualquer tag HTML que você tentar inserir dentro dela será tratada de forma literal e exibida como texto comum pelo navegador.

O elemento <title> não é exibido dentro da área útil da página (o corpo do site). Em vez disso, você poderá visualizá-lo diretamente no topo da aba do seu navegador:

Tag <meta>

O que é?

O elemento <meta> é usado para definir metadados (informações técnicas de bastidores) que não podem ser representados por outras tags do cabeçalho, como <title>, <link> ou <style>. Ele fornece instruções cruciais e legíveis por máquina (como navegadores, motores de busca e leitores de tela) sobre o documento, determinando a codificação de caracteres, configurações de exibição responsiva e otimizações de SEO. Trata-se de um elemento vazio (void element), o que significa que não possui corpo de texto interno nem tag de fechamento.

Sintaxe

<head>
  <!-- Define o mapa de caracteres suportado pelo site -->
  <meta charset="utf-8">

  <!-- Controla o comportamento de exibição em celulares (responsividade) -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- Define a descrição do site para exibição no Google -->
  <meta name="description" content="Aprenda HTML do zero com este guia completo e estruturado para iniciantes.">
</head>

Principais atributos

  • charset: Define a codificação de caracteres do documento. Configurar este atributo como "utf-8" é um padrão moderno e obrigatório para garantir que acentos, símbolos e emojis sejam renderizados de forma nativa e correta no navegador do usuário, evitando caracteres corrompidos.
  • name e content: Trabalham sempre em par. O atributo name define o tipo de metadado que está sendo declarado, enquanto o content fornece o valor ou instrução real para esse metadado:
    • name="viewport": Instrução indispensável para design responsivo. Definir seu conteúdo como "width=device-width" impede que os celulares simulem uma tela de computador desktop gigante, forçando o navegador móvel a utilizar a largura física real do aparelho.
    • name="description": Fornece um resumo preciso de aproximadamente 150 caracteres sobre a página, que os motores de busca (como o Google) extraem para criar o resumo descritivo (snippet) visível abaixo do link do seu site nas buscas.

Exemplo visual

As tags <meta> atuam silenciosamente nos bastidores e não geram componentes gráficos visíveis diretamente no corpo da página. No entanto, sua presença é o que possibilita que os emojis fiquem visíveis, que a tela do site se ajuste perfeitamente quando você deita seu celular e que um resumo chamativo apareça quando você pesquisa ou compartilha o seu link.

Status: 🟢 HTML5 — Atual

Tag <link>

O que é?

O elemento <link> é usado para estabelecer relações entre o documento HTML atual e recursos externos [1]. Ele é colocado exclusivamente dentro do cabeçalho <head> do documento [1] e funciona como um elemento vazio (void element), ou seja, não possui tag de fechamento nem conteúdo textual interno [3]. É a ferramenta padrão para carregar folhas de estilo CSS [1], configurar ícones da aba do navegador (favicons) [1] e realizar otimizações avançadas de carregamento [1, 4].

Sintaxe

<head>
  <!-- Vinculando um arquivo de estilo CSS externo -->
  <link rel="stylesheet" href="estilos/estilo.css">

  <!-- Definindo o favicon (ícone) da aba do navegador -->
  <link rel="icon" href="imagens/favicon.ico" type="image/x-icon">

  <!-- Otimização de performance (pré-carregamento de recurso) -->
  <link rel="preload" href="fontes/minha-fonte.woff2" as="font" type="font/woff2" crossorigin>
</head>

Principais atributos

* rel (obrigatório): Especifica a relação entre o documento atual e o recurso apontado [1]. Os valores mais comuns são "stylesheet" (para arquivos CSS), "icon" (para o favicon do site) [1] e "preload" (para pré-carregar recursos de alta prioridade antes que o parser do navegador trave a renderização) [1, 4].
* href: Define o endereço de destino (URL absoluta ou caminho relativo) do arquivo ou recurso externo que se deseja vincular [1].
* type: Indica o formato do recurso vinculado por meio de seu tipo MIME (como "text/css" ou "image/x-icon") para ajudar o navegador a interpretá-lo corretamente [5].
* crossorigin: Utilizado para configurar requisições de origem cruzada (CORS) quando o recurso carregado (como fontes ou mídias) está em outro servidor de terceiros [6].

Exemplo visual

Por residir no cabeçalho invisível <head>, a tag <link> não exibe nenhuma caixa ou botão diretamente no corpo do site [1]. No entanto, seu impacto visual é absoluto: sem ela, o navegador não carregaria o design, as cores e as fontes definidas no arquivo CSS externo [1], exibindo o site apenas em texto puro.

Status: 🟢 HTML5 — Atual

Tag <script>

O que é?

O elemento <script> é utilizado para embutir ou referenciar código executável (geralmente JavaScript) dentro de um documento HTML [1]. Ele é o principal responsável por adicionar comportamento dinâmico, lógica e interatividade em tempo real às páginas da web, transformando documentos estáticos em aplicações interativas [2-4].

Sintaxe

<!-- Script embutido interno -->
<script>
  console.log("Olá! Este script está rodando diretamente no HTML.");
</script>

<!-- Script externo com carregamento adiado (altamente recomendado para performance) -->
<script src="js/app.js" defer></script>

Principais atributos

* src: Especifica a URL ou o caminho relativo do arquivo de script externo a ser carregado [5, 6]. Nota de Boas Práticas: Quando você utiliza o atributo src, qualquer código digitado dentro do corpo da tag <script> é completamente ignorado pelo navegador [5].
* defer: Atributo booleano que indica ao navegador que o script externo deve ser baixado em segundo plano e executado apenas após o parsing completo do documento HTML [7, 8]. Isso impede que o carregamento do script bloqueie a renderização inicial da página, otimizando o tempo de carregamento [5, 7, 8].
* async: Atributo booleano que instrui o navegador a baixar o script em segundo plano e executá-lo imediatamente assim que o download for concluído, pausando temporariamente o parser do HTML se necessário [8-10]. Indicado para scripts independentes que não dependem da ordem do DOM (como ferramentas de análise e trackers).
* type: Define o tipo de script [1]. O padrão para JavaScript moderno pode ser omitido, mas aceita valores como "module" (para carregar módulos ES6) [11, 12] ou tipos customizados de dados (como type="application/json") para armazenar dados brutos a serem lidos por outros scripts posteriormente [1, 13].

Exemplo visual

A tag <script> é invisível na tela e não gera renderização gráfica direta no layout do navegador [8, 10]. No entanto, seu impacto visual é percebido de forma indireta através do comportamento dinâmico que ela cria na interface — como o disparo de alertas, a abertura de menus colapsáveis ou a modificação de textos e estilos do DOM em tempo real [6, 14].

Status: 🟢 HTML5 — Atual

Tag <style>

O que é?

O elemento <style> contém informações de estilização internas que são aplicadas diretamente aos elementos do próprio documento HTML no qual ele está inserido [1]. Ele abriga regras CSS que determinam a apresentação visual e o design da página [1]. Embora folhas de estilo externas vinculadas (gerenciadas pela tag <link>) sejam mais convenientes e recomendadas para a manutenção de sites com múltiplos documentos [2], o uso da tag interna <style> é muito útil para prototipagem rápida ou para criar estilos exclusivos e pontuais de uma única página específica [2].

Sintaxe

<head>
  <style>
    body { 
      background: navy; 
      color: yellow; 
    }
  </style>
</head>

Principais atributos

* media: Permite definir listas de consultas de mídia (media queries) válidas [3], condicionando a aplicação das regras de estilo declaradas a estados ou recursos específicos do dispositivo (como uma largura de tela delimitada por condições de mídia) [4].

Exemplo visual

Como um elemento técnico de cabeçalho, a tag <style> não exibe um bloco visível de forma direta na tela [5]. Contudo, seu efeito transforma completamente a aparência visual de todo o corpo da página, aplicando cores e designs específicos aos elementos renderizados para o usuário [1, 6].

Status: 🟢 HTML5 — Atual

Tag <div>

O que é?

O elemento <div> (do inglês division ou divisão) funciona como um contêiner genérico em nível de bloco (block-level element) [1, 2]. Ele não possui nenhum valor semântico intrínseco [2, 3]. Seu propósito exclusivo é agrupar outros elementos para fins de estilização visual via CSS ou para servir de gancho em manipulações dinâmicas com JavaScript [1, 3, 4]. Ele não causa nenhum efeito visual no layout até que seja estilizado [1]. Embora seja uma ferramenta indispensável, os desenvolvedores devem priorizar tags semânticas estruturais (como <section> ou <article>) sempre que o conteúdo possuir um significado claro [4-6].

Sintaxe

<!-- Agrupando elementos para estilização em bloco -->
<div class="cartao-noticia">
  <h3>Destaque do Dia</h3>
  <p>O HTML Living Standard é o padrão atual da web.</p>
</div>

Principais atributos

Por ser um contêiner genérico, a tag <div> não possui atributos específicos de comportamento, mas depende fortemente da aplicação de atributos globais [2]:
* class: Usado para associar classes de estilo CSS e aplicar regras de design ou esquemas de layout modernos, como Flexbox ou CSS Grid [1, 2].
* id: Define um identificador único, fundamental para estilizações altamente específicas ou para captura e manipulação do elemento através de scripts de comportamento [2].
* style: Permite a inclusão de regras CSS diretamente em linha, embora o uso de arquivos externos seja a prática recomendada.

⚠️ Alerta de Acessibilidade (a11y): Evite usar <div> para simular elementos interativos, como botões (<button>) ou links (<a>) [7, 8]. Ao fazer isso, as características nativas de acessibilidade (foco do teclado, acionamento por teclas de espaço/enter e leitura de tela) são perdidas, exigindo que você programe manualmente toda a acessibilidade por meio de scripts e ARIA complexos [7-9].

Tag <span>

O que é?

O elemento <span> funciona como um contêiner em linha genérico (inline-level container) para conteúdo de fraseado (phrasing content) [1]. Assim como o <div>, ele não possui nenhum significado semântico intrínseco [1, 2]. Seu propósito é puramente isolar e agrupar partes de um texto ou elementos em linha para aplicar estilizações com CSS ou manipulá-los dinamicamente via JavaScript [1, 2]. Enquanto o <div> gera uma caixa em nível de bloco (block-level), o <span> opera no nível da linha, sem forçar uma quebra de linha no fluxo do texto [1].

Sintaxe

<p>Este é um texto comum com uma <span class="texto-destaque">palavra estilizada</span> no meio.</p>

Principais atributos

Por ser um contêiner genérico, a tag <span> não possui atributos de comportamento exclusivos, dependendo do uso de atributos globais [1]:
* class: Permite associar uma ou mais classes de estilização CSS para formatar o visual daquele trecho específico do texto [1].
* id: Define um identificador único para o nó, facilitando manipulações dinâmicas de scripts ou a aplicação de regras de design altamente específicas [1].
* lang: Permite especificar o idioma de um termo ou expressão isolada dentro do parágrafo, garantindo que sintetizadores de voz façam a pronúncia correta em recursos de acessibilidade [1, 3].

⚠️ Regra de Aninhamento Proibida: Como a <div> é renderizada como um bloco e a <span> é renderizada em linha, **é incorreto e proibido colocar um elemento de bloco dentro de um elemento em linha** (ou seja, você nunca deve colocar uma <div> dentro de uma <span>) [4].

Tag <p>

O que é?

O elemento <p> é utilizado para delimitar um bloco de texto contínuo como um parágrafo [1]. Ele se caracteriza por ser um elemento não substituído que possui um espaçamento vertical nativo padrão aplicado automaticamente pelo navegador do usuário [1].

Sintaxe

<p>Este é um parágrafo estruturado em HTML.</p>

Principais atributos

A tag <p> aceita apenas os atributos globais comuns do HTML, tais como class, id, lang e style [2]. Ela não possui atributos de comportamento específicos ou exclusivos.

Notas de Boas Práticas:
* Sempre utilize a tag de fechamento: Embora o analisador do navegador permita a omissão da tag de fechamento </p> se o elemento for seguido imediatamente por outro parágrafo ou se não houver mais conteúdo no elemento pai [3], a falta de fechamento é um erro comum de iniciantes que pode forçar o navegador a adivinhar a estrutura do código, levando a renderizações visuais imprevistas [4, 5].
* Evite o cruzamento de elementos: O aninhamento incorreto de elementos impede a montagem linear e correta da árvore do DOM [6]. O navegador ativará rotinas automáticas de correção de erros para tentar estruturar o layout, o que prejudica a performance e a consistência visual do seu site [6].

Tag <a> (Âncora ou Link)

O que é?

O elemento <a> (do inglês anchor ou âncora) é o responsável por criar hiperlinks na web. Ele serve para conectar a página atual a outras páginas, arquivos locais, endereços de e-mail, números de telefone ou até mesmo ancorar destinos de rolagem dentro do próprio documento.

Sintaxe

<!-- Link padrão abrindo na mesma aba -->
<a href="https://www.exemplo.com">Visite nosso site</a>

<!-- Link seguro abrindo em uma nova aba -->
<a href="https://www.exemplo.com" target="_blank" rel="noopener noreferrer">Abrir em nova aba</a>

Principais atributos

  • href: O atributo principal e obrigatório. Ele define o destino final do link, que pode ser uma URL absoluta (como https://...) ou uma rota relativa interna (como sobre-nos.html).
  • target: Determina onde a página de destino será aberta. O valor mais utilizado é "_blank", que força o navegador a abrir o link em uma nova aba ou janela.
  • rel: Especifica a relação entre a página atual e o link de destino. Ao usar target="_blank", é uma boa prática crítica de segurança adicionar rel="noopener noreferrer" para proteger o usuário de possíveis scripts maliciosos de controle de abas de terceiros. Também pode receber valores de SEO como nofollow, sponsored (para parcerias pagas) ou ugc (para conteúdos gerados por usuários).

Exemplo visual

Tag <img>

O que é?

O elemento <img> serve para embutir imagens diretamente em uma página web [1]. Ele é classificado como um elemento vazio (void element), o que significa que não possui corpo de conteúdo nem tag de fechamento [2, 3]. Além disso, ele é um elemento substituído, pois representa um recurso externo cuja renderização e estilização nativa são controladas pelas regras do próprio navegador (agente de usuário) [4].

Sintaxe

<img src="caminho/foto-cachorro.jpg" alt="Um filhote de Golden Retriever correndo no parque" width="400" height="300" loading="lazy">

Principais atributos

* src (obrigatório): Define a URL ou o caminho relativo do arquivo de imagem a ser carregado [1].
* alt (acessibilidade): Fornece uma descrição textual alternativa para a imagem [1]. Trata-se de uma diretriz crítica de acessibilidade (WCAG), sendo lida por softwares leitores de tela para usuários com deficiência visual [1, 5]. Também é de extrema importância para SEO, ajudando motores de busca a compreenderem e indexarem o conteúdo visual [6, 7]. Para imagens meramente decorativas, o atributo deve ser deixado explicitamente vazio (alt=""), orientando os leitores de tela a ignorarem a imagem [7].
* width e height: Definem a largura e altura físicas da imagem em pixels [1]. Configurar essas dimensões ajuda no controle do Cumulative Layout Shift (CLS), permitindo que o navegador reserve o espaço do layout antes do carregamento da imagem, evitando saltos visuais na página [8].
* loading: Quando definido como "lazy", adia o carregamento de imagens que estão fora da tela até que o usuário role a página para perto delas, economizando banda e melhorando a velocidade geral do site [9, 10].

Exemplo visual

O navegador exibirá o gráfico renderizado no layout. Se a imagem não puder ser carregada por erro de rede ou de caminho, o navegador exibirá o ícone de imagem quebrada acompanhado do texto alternativo contido no atributo alt.

Tag <h1> (e a hierarquia de cabeçalhos de <h1> a <h6>)

O que é?

O elemento <h1> define o cabeçalho de seção de nível mais alto e importante de uma página web, seguido em ordem decrescente de relevância pelas tags de <h2> a <h6> [1]. Eles são fundamentais para estabelecer uma estrutura semântica clara e gerar um contorno de documento (document outline) consistente [2, 3], auxiliando diretamente tecnologias assistivas (como leitores de tela) e motores de busca (SEO) a compreenderem a relevância e a divisão de assuntos do site [4-6].

Sintaxe

<h1>Título Principal Único da Página</h1>
<h2>Seção Principal do Conteúdo</h2>
<h3>Subtópico Interno da Seção</h3>

Principais atributos

Estes elementos aceitam exclusivamente os atributos globais comuns do HTML [7]. Não possuem atributos específicos de comportamento.

Boas Práticas e Regras de Negócio:
* Use apenas um único <h1> por documento: Ele deve funcionar estritamente como o título principal do assunto tratado no arquivo inteiro [2, 3].
* Progressão lógica estrita: Deve-se avançar de forma estritamente sequencial e decrescente (ex: passe de um <h2> para um <h3>; ir de um <h1> diretamente para um <h3> ou <h4> pulando níveis é incorreto) [2, 3] para garantir a integridade da árvore estrutural e permitir que leitores de tela gerem sumários de navegação corretos para o usuário [2].
* Propósito semântico, não visual: Nunca utilize tags de cabeçalho apenas para estilizar tamanhos de texto ou aplicar negritos [8]. Se você deseja apenas alterar o tamanho ou peso visual do texto, utilize regras de formatação e design em CSS [8, 9].

Tag <h2>

O que é?

O elemento <h2> define o segundo nível de cabeçalho na hierarquia estrutural de uma página web, situando-se logo abaixo do <h1> [1]. Ele é utilizado para marcar as seções e divisões principais do conteúdo de um documento [2, 3]. Estabelecer uma estrutura lógica com a tag <h2> é uma prática indispensável para gerar um contorno de documento (document outline) consistente, auxiliando motores de busca na indexação (SEO) [2, 4] e permitindo que leitores de tela ofereçam atalhos de navegação eficientes para usuários com deficiência visual [2, 5].

Sintaxe

<h1>Título Principal da Página</h1>

<h2>Seção 1: Fundamentos Sintáticos</h2>
<p>Conteúdo introdutório sobre sintaxe...</p>

<h2>Seção 2: Estrutura de Documentos</h2>
<p>Explicação sobre a árvore DOM...</p>

Principais atributos

Assim como os demais cabeçalhos de <h1> a <h6>, esta tag aceita apenas os atributos globais do HTML (como id, class, lang ou style) [6]. Ela não possui nenhum atributo de comportamento específico.

Regras Técnicas e Boas Práticas:
* Progressão lógica estrita: Avance sempre de forma sequencial e decrescente. Você só deve utilizar um <h2> após declarar um <h1>, e nunca deve saltar níveis (por exemplo, ir diretamente de um <h1> para um <h3>) [2, 3].
* Finalidade Semântica: Jamais aplique a tag <h2> meramente para fins estéticos (como aumentar o tamanho ou aplicar negrito a um texto comum). Caso queira apenas estilizar visualmente um trecho, utilize regras CSS [2].

O que é?

O elemento <h3> representa o terceiro nível de cabeçalho na hierarquia de um documento HTML [1]. Ele é utilizado para marcar subseções ou tópicos específicos que estão contidos dentro de uma seção principal iniciada por um <h2> [2]. Assim como os demais cabeçalhos, ele é fundamental para a criação de um contorno de documento (document outline) claro, auxiliando os motores de busca no ranqueamento (SEO) e fornecendo pontos de referência cruciais para leitores de tela [1, 3].

Tag <br>

O que é?

O elemento <br> produz uma quebra de linha em um texto (carriage-return) [1]. Ele é categorizado sintaticamente como um elemento vazio (void element), o que significa que ele não pode conter outros conteúdos HTML ou texto interno e não necessita de uma tag de fechamento correspondente [2, 3].

Sintaxe

<p>
  Primeira linha de um endereço<br>
  Segunda linha do endereço
</p>

Contexto de Uso e Recomendações

* Propósito semântico: O elemento é útil principalmente para escrever textos onde a divisão física de linhas é um fator significativo para a estrutura da própria informação, como no caso de poemas ou endereços postais [1].
* A barra de fechamento (/): Embora em alguns exemplos de marcação XML ou XHTML seja comum ver a barra ao final (como em <br />) para atender a regras de serialização estritas [4], essa barra final de fechamento não é necessária na sintaxe padrão do HTML [5].

Tag <hr>

O que é?

O elemento <hr> representa uma quebra temática entre elementos em nível de parágrafo [1]. É semanticamente definido como um separador [2], sendo ideal para marcar transições importantes na estrutura do texto, como uma mudança de cena em uma história ou uma alteração de tópico dentro de uma mesma seção [1]. Embora historicamente tenha sido muito associado a um propósito puramente estético (exibir uma linha horizontal), o HTML moderno o redefiniu para ser totalmente independente de mídia, focando em seu papel estrutural [3].

Sintaxe

<p>Este é o desfecho do primeiro tópico.</p>

<hr>

<p>Este é o início de um novo assunto correlato.</p>

Principais atributos

A tag <hr> aceita apenas os atributos globais do HTML (como id, class ou style) para sua identificação e estilização [4].

Cuidados Técnicos e Semânticos:
* Semântica Coerente: Evite atribuições que entrem em conflito com o seu propósito. Por exemplo, declarar <hr role="cell"> é semanticamente incorreto (nonsensical), uma vez que um separador de conteúdo não pode atuar de forma simultânea como uma célula de tabela [2].
* Evite Erros de Aninhamento: Inserir o <hr> diretamente dentro de uma tabela de forma inválida (como no fragmento <table><hr>...) faz com que o interpretador do navegador execute uma recuperação de erro altamente contraintuitiva, gerando uma árvore DOM na qual o <hr> é posicionado como um elemento irmão anterior à própria tabela [5].

Exemplo visual

Na tela do usuário, a tag atua separando de maneira limpa as seções de texto [1]. Toda a sua apresentação visual (como cor, largura, margens ou estilo da linha) deve ser controlada exclusivamente por propriedades no CSS [3, 6].

Tag <header>

O que é?

O elemento <header> representa um grupo de conteúdos introdutórios ou auxiliares de navegação, servindo como cabeçalho para o documento inteiro ou para uma seção interna específica (como um artigo ou um grupo de tópicos) [1, 2]. Ele funciona como um contêiner para abrigar títulos estruturais, logotipos de marcas, slogans de apoio, metadados de autoria ou formulários de pesquisa rápida [3, 4].

Sintaxe

<!-- Cabeçalho global do site -->
<header>
  <img src="imagens/logo.png" alt="Logotipo do Curso">
  <nav>
    <a href="#home">Início</a>
    <a href="#modulo-2">Módulo 2</a>
  </nav>
</header>

<!-- Cabeçalho interno de um artigo autônomo -->
<article>
  <header>
    <h2>A Gênese do HTML Living Standard</h2>
    <p>Publicado por <span itemprop="author">Desenvolvedor Sênior</span></p>
  </header>
  <p>O HTML moderno passou a ser mantido pelo WHATWG como um padrão contínuo...</p>
</article>

Principais atributos

O elemento <header> aceita unicamente os atributos globais comuns do HTML (como id, class, style e lang). Ele não possui atributos de comportamento específicos ou de controle de dados exclusivos de sua especificação.

Especificações Técnicas e Acessibilidade (a11y):
* Papel ARIA Implícito (role="banner"): Quando posicionado diretamente sob o elemento raiz do corpo da página (ou seja, sem estar aninhado em subseções como <article>, <aside>, <main>, <nav> ou <section>), o <header> assume automaticamente o papel implícito de role="banner" [1]. Isso cria um marco de acessibilidade crucial que permite que leitores de tela e tecnologias assistivas identifiquem o cabeçalho global do site instantaneamente [1, 5].
* SEO e Performance: Buscadores priorizam a indexação e dão maior relevância a palavras-chave encontradas dentro de tags semânticas estruturais [6]. O uso da tag nativa também elimina o aninhamento excessivo de divisores genéricos (div soup), gerando arquivos com tamanhos de código mais leves e fáceis de carregar [6].

Exemplo visual

Sendo um elemento estrutural em nível de bloco, o <header> não aplica nenhuma estilização visual intrínseca (como margens, cores de fundo ou bordas). Todo o seu design de apresentação e comportamento de layout (como fixar o menu no topo usando propriedades de posicionamento) deve ser declarado e gerenciado de forma isolada no CSS [7].

Tag <nav>

O que é?

O elemento <nav> define uma seção da página que contém blocos ou conjuntos de links destinados à navegação, sejam eles para navegação externa (outros documentos) ou interna (âncoras dentro do próprio documento) [1, 2]. Ele funciona como um marco de acessibilidade semântico (landmark element) essencial para tecnologias assistivas [3, 4]. Leitores de tela e navegadores identificam essa tag para fornecer atalhos de navegação rápida por teclado para usuários com deficiência visual, permitindo saltar diretamente para as seções de menu da página sem passar por conteúdos redundantes de cabeçalhos [3, 5].

Sintaxe

<!-- Menu de navegação principal da página -->
<nav aria-label="Navegação Principal">
  <ul>
    <li><a href="/home/">Início</a></li>
    <li><a href="/sobre/">Sobre</a></li>
    <li><a href="/contato/">Contato</a></li>
  </ul>
</nav>

Principais atributos

A tag <nav> aceita apenas os atributos globais comuns do HTML, mas depende fortemente de boas práticas de estruturação e de acessibilidade (a11y) [6, 7]:
* Papel ARIA Implícito (role="navigation"): Por padrão, o navegador atribui à tag o papel implícito de navegação sem a necessidade de declará-lo manualmente no código [5].
* Uso do aria-label: É uma boa prática recomendada para acessibilidade e SEO o uso do atributo aria-label quando o documento possui mais de uma seção <nav> (ex: navegação principal no cabeçalho e navegação de suporte no rodapé) [7, 8]. Isso ajuda tecnologias assistivas a nomear e diferenciar os menus corretamente [7].
* Estruturação com listas: A especificação e a iniciativa WAI da W3C orientam que os links de navegação sejam organizados usando elementos de listas ordenadas ou não ordenadas (<ul> ou <ol> com <li>) [5, 7]. Essa árvore semântica informa a leitores de tela a contagem de itens de menu disponíveis, melhorando drasticamente a experiência do usuário assistido [5, 9].

Tag <main>

O que é?

O elemento <main> define o conteúdo principal, dominante e exclusivo do corpo (<body>) de um documento HTML [1, 2]. Ele serve para encapsular a seção central de informações que está diretamente relacionada ou que expande o tópico ou a funcionalidade central da página [1]. Por representar o núcleo exclusivo do documento, deve haver apenas um único elemento <main> ativo por página [3, 4], e ele não deve conter conteúdos que se repetem em outras páginas do site, tais como barras de navegação globais, cabeçalhos, rodapés, logotipos ou formulários de busca comum [5].

Sintaxe

<!doctype html>
<html lang="pt-BR">
  <head>
    <meta charset="utf-8">
    <title>Artigo de Estudos</title>
  </head>
  <body>
    <header>
      <!-- Cabeçalho global do site (não repetido no main) -->
    </header>

    <!-- Apenas um elemento main por página -->
    <main>
      <article>
        <h1>Introdução ao HTML Semântico</h1>
        <p>O HTML5 trouxe tags muito importantes para a acessibilidade...</p>
      </article>
    </main>

    <footer>
      <!-- Rodapé global do site -->
    </footer>
  </body>
</html>

Principais atributos

O elemento <main> aceita apenas os atributos globais do HTML (como id e class) e não possui atributos de comportamento exclusivos de sua especificação [6]. Suas vantagens técnicas de arquitetura se concentram em:
* Acessibilidade (a11y): Ele possui o papel semântico implícito de role="main" perante a árvore de acessibilidade [6-8]. Ele atua como um marco de navegação (landmark element) indispensável para tecnologias assistivas [7, 9-11]. Leitores de tela mapeiam essa tag para criar atalhos de navegação rápida via teclado, permitindo que usuários com deficiência visual ignorem blocos redundantes de cabeçalho ou menu e saltem diretamente para a área de conteúdo útil [7, 9-12].
* Restrição de Aninhamento: Para manter a conformidade técnica, o elemento <main> deve ser mantido de forma hierárquica clara e não deve ser aninhado dentro de outros marcos de seção do site, como <header>, <footer>, <nav> ou <aside> [6, 12].

Exemplo visual

Sendo um elemento semântico estrutural em nível de bloco, o <main> não aplica nenhuma estilização visual visível (como bordas, preenchimentos ou cores) por padrão. O seu papel é puramente delimitar a área onde a informação de maior relevância da página está concentrada.

Tag <section>

O que é?

O elemento <section> define uma seção genérica e autônoma de um documento que agrupa conteúdos relacionados tematicamente [1-3]. Ao contrário de contêineres puramente estéticos e sem semântica como a tag <div> [1, 4, 5], a <section> atua ativamente na segmentação de tópicos e na organização estrutural do layout [1]. Como diretriz de boa prática, as seções devem quase sempre conter um título interno (cabeçalhos de <h2> a <h6>) que identifique o tema do grupo de conteúdo [2, 3, 6].

Diferença Semântica Crucial (<article> vs. <section>): O elemento <article> serve para encapsular uma composição totalmente autônoma, independente e distribuível por si só, como um post de blog ou notícia [1, 2, 7]. Já a <section> serve para agrupar e subdividir conteúdos relacionados sob um contexto maior da página [2, 7].

Sintaxe

<!-- Subdivisão temática com cabeçalho associado -->
<section>
  <h2>Fundamentos Sintáticos</h2>
  <p>A base do desenvolvimento em HTML reside no modelo de árvore de nós...</p>
</section>

Principais atributos

A tag <section> aceita os atributos globais comuns do HTML (como id, class, lang e style) [4]. No entanto, seu comportamento semântico e suas regras de aninhamento apresentam as seguintes particularidades técnicas:
* Papel ARIA Implícito (role="region"): Na árvore de acessibilidade exposta aos leitores de tela, a tag assume o papel implícito de role="region" apenas se possuir um nome acessível definido (geralmente fornecido por meio do atributo aria-label ou aria-labelledby referenciando o título da própria seção) [1].
* Restrição de Aninhamento Semântico: Para garantir uma semântica consistente, a especificação proíbe o aninhamento de um elemento <section> dentro de um elemento <kbd>, visto ser sem sentido lógico declarar que uma seção inteira da página represente um texto digitado pelo teclado do usuário [8].

Por ser um elemento estrutural, o <section> não possui nenhum efeito direto sobre o design visual ou renderização estética da página, servindo exclusivamente para definir e categorizar semanticamente o seu conteúdo [9].

Tag <article>

O que é?

O elemento <article> representa uma composição autônoma e autocontida em um documento, página, aplicativo ou site, que se destina a ser distribuível ou reutilizável de forma independente (por exemplo, em feeds de notícias ou sindicação) [1]. Exemplos típicos incluem uma postagem de blog, um artigo de jornal ou revista, um cartão de produto (product card), um comentário enviado por usuário ou um widget interativo [1].

Diferença Semântica Crucial (<article> vs. <section>): O elemento <article> é usado para conteúdos independentes que fazem sentido completo mesmo se fossem removidos da página e lidos de forma isolada [2-4]. Por outro lado, a <section> serve para agrupar conteúdos relacionados sob um mesmo tema dentro de um contexto maior da página [2-4].

Sintaxe

  <header>
    <h2>Novidades do HTML Living Standard</h2>
    <p>Publicado em <time datetime="2026-09-05">05 de setembro de 2026</time></p>
  </header>
  
  <p>O padrão agora é atualizado continuamente pelo WHATWG...</p>
  
  <footer>
    <p>Categoria: Desenvolvimento Web</p>
  </footer>
</article>

Principais atributos

O elemento <article> aceita apenas os atributos globais comuns do HTML (como id, class, e os atributos de microdados itemscope e itemtype) [5-7]. Sua relevância técnica concentra-se em:
* Papel ARIA Implícito (role="article"): O navegador atribui automaticamente a este elemento o papel implícito de role="article" para tecnologias assistivas [1, 2]. Isso ajuda leitores de tela a identificarem onde começa e termina um conteúdo independente [2].
* SEO e Dados Estruturados: Mecanismos de busca e leitores de tela dão maior peso a conteúdos encapsulados em tags semânticas [2, 8]. A tag <article> é o contêiner ideal para alinhar marcações de Schema.org (como TechArticle ou NewsArticle), mapeando de forma confiável propriedades como título (headline), autor e data de publicação para evitar discrepâncias entre o que o usuário lê e o que o buscador indexa [7, 9, 10].

Como um elemento estrutural de bloco, o <article> não aplica nenhuma formatação visual ou estilização estética nativa (como bordas ou cores de fundo) por padrão. Ele atua puramente como uma fronteira semântica invisível no layout, que deve ser estilizada conforme necessário via CSS.

Tag <sub>
